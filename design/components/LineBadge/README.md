Plakietka numeru linii: prostokąt 24 px o promieniu 3 px z grubym numerem Archivo 800, wyłącznie dla prawdziwych numerów linii.

**Dostarczasz:** rzeczywisty numer linii z danych GTFS (`route_short_name`). Nie masz numeru: użyj kreskowanego wariantu `XX` (`.idx-badge--ph`).

- Tło `idx-accent`, numer `idx-on-accent`. Numer w cyfrach tabelarycznych.
- Nie rysuj plakietek dla nazw miast, rodzaju przewoźnika ani kategorii. Nie wymyślaj numerów.
- W kontekście obok plakietki podaj nazwę „linia 11” w mono, żeby czytnik ekranu miał tekst.
