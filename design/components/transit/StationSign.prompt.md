Dark signage panel: station name, direction, serving lines, optional exit strip — use as a page header or hero object for a station/place.
```jsx
<StationSign metaLeft="Stacja" metaRight="Linia M1 · M2" title="Świętokrzyska" subtitle="Kierunek: Kabaty"
  lines={[{label:'M1',line:'red'},{label:'M2',line:'yellow'}]} exit="Plac Mikołaja Kopernika" />
```
The only rounded surface in the system (12px).
