Glyph from Material Symbols Sharp (filled, weight 700) — the signage-weight icon set for every UI icon.
```jsx
<Icon name="north_east" size={24} />
<Icon name="train" size={20} fill={0} weight={400} title="Train" />
```
Defaults are filled + bold to match transit pictograms. Use `fill={0}` only in dense tool UI.
