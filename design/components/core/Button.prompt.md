Square-cornered action button in bold Helvetica — use for every clickable action.
```jsx
<Button>Show timetable</Button>
<Button variant="accent" iconRight="east">Plan route</Button>
<Button variant="secondary" size="sm">Cancel</Button>
```
Variants: primary, accent (max one per view), secondary, ghost, inverse (on ink/sign surfaces). Sizes sm 32 / md 44 / lg 56. Radius is always 0.
