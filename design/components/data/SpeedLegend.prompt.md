Legend for the sequential speed scale (5 classes, slow→fast) plus "no data" grey and hatched "thin sample" — use next to every speed map or chart.
```jsx
<SpeedLegend />
<SpeedLegend title="Speed" slowLabel="slower" fastLabel="faster" noDataLabel="no data" thinLabel="thin sample" />
```
Theme-aware via --speed-* tokens (light: slow = dark plum; night: slow = pale peach).
